About TreeScope

TreeScope is an original Data Structures learning project designed to explain Binary Search Trees using interactive visualization and detailed algorithm animations.

TreeScope includes insertion, deletion, searching, recursive traversals, linear animation controls, interactive tree comparison and learning presets.

How a BST Works

A Binary Search Tree is a binary tree where every node's left subtree contains smaller values and its right subtree contains greater values.

Our example starts with 50 as the root, 30 to its left and 70 to its right. The initial tree has seven unique nodes and height 2 (measured in edges).

Use Insert, Delete and Search to explore the algorithm. Traversal buttons show recursive calls and backtracking. Pause and advance through steps using the controls above the playground.
